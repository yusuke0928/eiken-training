# 英検準2級トレーニング

中学3年生向けの英検準2級対策アプリ（PWA / 学習データは端末内のみ）。

**▶ https://yusuke0928.github.io/eiken-training/**

スマホで開いて「ホーム画面に追加」すると、アプリとして起動します。
一度開けば、オフラインでも使えます（通学中に電波が切れても大丈夫）。

> 学習データはその端末のブラウザの中だけに保存されます。サーバーには何も送信されません。
> 端末やブラウザを変えるとデータは引き継がれません。

## 動かす

```bash
npm install
npm run dev        # http://localhost:5173
```

スマホで試すときは同じ Wi-Fi につないで、表示される Network の URL を開く。
ホーム画面に追加すればアプリのように起動できる。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 問題データ検証 → 型チェック → 本番ビルド |
| `npm run validate` | 問題データの整合性チェックのみ |
| `npm run smoke` | 実機スモークテスト（別ターミナルで `npm run dev` が必要） |
| `npm run icons` | アプリアイコンを再生成（`public/icons/`） |

## いま入っているもの

**Build 1 — 選択問題**

- 実力診断テスト（20問・本番の大問構成を縮めたもの）
- ミニ演習（1回8問／期限が来た復習 50%・弱点 30%・新規 20%）
- 論点別トレーニング（語彙・文法・会話・読解のタグ別）
- 解説シート（正解の理由 ＋ **他の選択肢がなぜダメか** ＋ 語句）
- 復習ボックス（Leitner 5箱の間隔反復）
- 連続日数（週2回まで自動でおやすみ）・受験日カウントダウン
- ダークモード / 端末内保存（IndexedDB）

**Build 2 — ライティング道場（14題）**

- 意見論述8題・Eメール6題。すべてモデル解答つき（語数は検証済み）
- 構成テンプレート（この順に並べるだけで形になる5ステップ）
- 書きながらの**形式チェック**（ヘッダー直下に固定表示）
  - 語数が範囲内か／Eメールは疑問符が2つ以上／意見論述は First・Second とまとめの文
  - ⚠️ 内容の良し悪しは判定しない。数えられることだけ
- 公式の採点観点そのままの自己採点（Eメール12点／意見論述16点）
- スマホの自動修正・自動大文字化はオフ（本番は手書きなので）

**Build 3 — リスニング（30問）と適応出題**

- 第1部10問（応答文選択・3択）／第2部10問（会話の内容一致）／第3部10問（文の内容一致）
- 放送の長さは本番に合わせてある（合計19.4分＋指示文 ≒ 約25分）
- 端末の読み上げ機能で音声を再生（男女で声を変える）
  - 第1部は**選択肢も音声のみ**。本番と同じく、再生するまで文字を出さない
  - 練習モードでのみ「ゆっくり」「もう一度」「スクリプト」を許可
  - ⚠️ 本番の音源とは別物。形式に慣れる用途。音が出ない端末では文字に切り替えられる
- **重点配分が使うほど自動で傾く**（`src/engine/mastery.ts`）
  - 直近を重く見た正答率（減衰0.85）／試行が少ないタグは全体平均へ寄せる
  - 苦手・放置ぎみ・未着手に出題が寄る。設定項目はなし
  - 「いまの重点」画面で、何が増えているかとその理由が見える

**Build 4 — 模擬テスト**

- 本番と同じ構成：筆記31題（選択29＋ライティング2）80分 ＋ リスニング30問
- 範囲はフル／筆記のみ／リスニングのみから選べる
- 残り時間表示（10分で色が変わる・0で自動的にリスニングへ）
- 問題一覧シートで未回答・見直しフラグを確認して飛べる
- 中断しても24時間は続きから再開できる
- リスニングは放送1回・スクリプトなし・放送後は約10秒で次へ
- ライティングは語数カウンターのみ（テンプレも形式チェックも出さない）
- 終了後：技能別スコア／CSE目安／時間の使い方の講評／誤答は復習ボックスへ

## 問題を足す

`content/pre2/*.json` に追記するだけ。ビルド時に検証が走る。

```jsonc
{
  "id": "p2-v-041",            // 重複不可
  "section": "r-vocab",
  "tags": ["vocab:verb"],      // src/types.ts の TAG_LABEL にあるもの
  "difficulty": 2,             // 1|2|3
  "stem": "I can't ( ) ...",   // ( ) が空所として描画される
  "choices": ["正解", "誤答1", "誤答2", "誤答3"],
  "answerIndex": 0,            // ★ 正解は必ず先頭に書く
  "translation": "…",
  "explanation": "なぜこの答えになるか",
  "distractorNotes": ["正解の意味", "誤答1の理由", "誤答2の理由", "誤答3の理由"],
  "vocab": [{ "word": "…", "meaning": "…", "example": "…" }]
}
```

**正解は必ず `choices` の先頭に書く。** 書きやすさとレビューのしやすさを優先し、
表示時に問題 id から決まる並びへ自動で入れ替えている（`src/lib/shuffle.ts`）。
そのままだと正解が全部 A になり「迷ったらA」を覚えてしまうため。
並びは id から決まるので、同じ問題は毎回同じ順序で出る。

ライティング課題は `content/pre2/writing.json`。`modelAnswer` は**語数の範囲内**でなければ
検証で落ちる（手本が範囲外だと手本にならないため）。Eメールは疑問符2つ以上、
意見論述は First / Second を含むことも検証される。

## 構成

```
content/pre2/       問題データ（コードから分離。本人が追加できる形）
src/
  content.ts        JSON の読み込みと正規化・選択肢の並び替え
  types.ts          問題・記録の型、セクション名・論点タグの日本語表示
  data/db.ts        IndexedDB（Dexie）・連続日数の計算
  engine/
    srs.ts          Leitner 5箱の間隔反復
    selector.ts     出題ミックスと適応難易度
    scoring.ts      CSE スコアの目安（※相対評価なので厳密な換算は不可）
  lib/
    exam.ts         受験日程とカウントダウン
    shuffle.ts      id から決まる選択肢の並び替え
  ui/               ボタン・カード・リングなどの共通部品
  features/         画面
scripts/            問題データ検証・スモークテスト
```

## 注意

- 収録している問題は**英検の形式に準拠したオリジナル**。過去問の本文はそのまま入れていない。
- CSE スコアの表示は正答率からの**目安**。実際の CSE は受験者全体の中での相対評価で決まる。
- データは端末内のみ。端末を変えると消える（バックアップ機能は未実装）。
